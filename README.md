# Desktop Lab

Small desktop apps, timers, and UI experiments built with Python and `PyQt5`.

## Projects

* `hourglass/` — Animated sand timer with presets, custom time, and flip control
* `scratchpad/` — Auto-saving quick desktop notes with character/line counts and copy/clear actions
* `colorlab/` — HEX and RGB color converter with live swatch, color picker, and clipboard copy
